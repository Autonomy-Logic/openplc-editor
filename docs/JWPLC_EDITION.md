# OpenPLC Editor - JWPLC Edition

Este fork es mantenido por JW Control y está basado en OpenPLC Editor.

## Objetivo

Permitir la instalación y validación de paquetes VPP firmados por JW Control para integración con JWPLC Basic.

## Cambios JW Control

- Se mantiene la llave oficial `openplc-2026`.
- Se agrega la llave pública `jwcontrol-2026`.
- El build se identifica como `OpenPLC Editor - JWPLC Edition`.

## Seguridad

La llave privada `jwcontrol-2026-private.pem` no forma parte de este repositorio y debe mantenerse en almacenamiento seguro de JW Control.
